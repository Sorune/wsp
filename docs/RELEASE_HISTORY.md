The historical source snapshots were consolidated on 2026-11-16. The original
initial repository commit and the original release publication dates are
retained. Reconstructed source commits retain the original snapshot author
dates; their committer dates identify the actual consolidation.

Historical binary downloads and checksums through v0.7.2 are the original
published assets, not newly rebuilt distributions. Their embedded build
revision refers to the original release source history, whereas historical
tags now identify the consolidated source snapshots. This is intentionally
not a claim of byte-for-byte reproducibility from the consolidated tags.
New releases are built from their corresponding release source commit and
carry verified build provenance.

The [original publication snapshot](PUBLICATION_SNAPSHOT.json) records the original repository creation timestamp, initial Git commit, original release IDs and publication times, and SHA-256 digests of the published assets. The original API responses and assets are retained privately. This is an archived observation, not a GitHub-issued attestation for the replacement repository.
